소개

2020년 4월부터 소프트웨어 개발자로 일하고 있으며, 실무 경력은 만 6년입니다. Growth 마케팅 플랫폼에서 Vue·Nuxt로 운영 도구와 고객 화면을 만들고, Node.js·AWS Lambda·PostgreSQL로 광고 성과와 문의 데이터를 처리했습니다.

랜딩 실험과 다국어 문의 접수부터 대용량 영상 관리까지 구현했습니다. 사내 업무에서는 n8n과 Notion을 연결해 AI 리서치·콘텐츠 생성 과정을 자동화했습니다.

이전에는 Java·Spring 기반 교육 서비스의 PG 결제와 본인인증을 개발하고, 공공 정보시스템 운영과 데이터 이관을 맡았습니다.

AI 모델 학습, 프롬프트 엔지니어링, 검색 증강 생성(RAG)에 관심을 두고 있습니다. 프롬프트 설계와 문서 기반 검색·응답 방식을 개인적으로 공부하며, 웹 서비스와 업무 자동화에 AI를 활용하는 방법을 탐구하고 있습니다.

최근 프로젝트

Growth 마케팅 플랫폼

성진에이치디에스 · 2024.09.02 ~ 재직 중 · 웹 풀스택 개발

광고 소재와 캠페인을 관리하고, 랜딩에서 접수한 문의를 광고 성과와 상담 업무에 연결하는 플랫폼입니다.

광고 지표 수집과 전환 API

Google Ads·Meta의 노출·클릭·비용을 정기 수집하는 배치와 조회 API를 개발했습니다. Google Ads·Meta·TikTok·Taboola·당근·카카오·OpenAI 등 7개 매체의 전환 API를 연동했습니다.

운영자가 한 화면에서 매체별 성과를 조회하고, 랜딩에서 접수한 문의를 광고 매체의 전환 이벤트로 전송할 수 있게 했습니다.

광고 연동 구현 상세
  • 랜딩에서 최초 유입 정보와 광고 클릭 식별자를 수집하고, 문의 접수 후 EventBridge로 매체별 전환 이벤트를 전송했습니다.
  • 전환 이벤트 중복을 확인하고, 실패한 문의 전환을 재시도하는 배치를 개발했습니다.
  • TikTok·네이버 Excel과 카카오 CSV 등 매체 리포트의 업로드를 지원했습니다.

랜딩페이지 A/B/C 실험

운영자가 실험 기간과 랜딩 변형을 설정·미리보기하고, 방문자에게 배정한 실험 안이 문의 제출까지 이어지도록 구현했습니다.

운영 화면에서 안별 고유 노출과 문의 건수를 비교하고, 캠페인 문의단가를 확인할 수 있게 했습니다.

랜딩 실험 구현 상세
  • 실행 시점의 설정을 스냅샷으로 고정하고, 예약·진행 중에는 화면과 API에서 랜딩폼 편집을 제한했습니다.
  • 페이지가 실제로 보이는 탭에서 노출을 기록하고, 서버에서 중복 노출과 문의 전환을 제외했습니다.
  • 실험 기간 검증, 편집 잠금, 결과 집계에 대한 회귀 테스트를 추가했습니다.

다국어 문의 접수와 상담 연동

한국어·영어·일본어·중국어 간체·베트남어를 지원하는 폼 편집과 공개 랜딩을 구현했습니다. 해외 전화번호는 국가별로 검증하고 국제 표준인 E.164 형식으로 저장했습니다.

운영자가 언어로 문의를 조회하고, 제출 당시의 질문과 답변을 운영 화면·Excel·Airtable에서 확인할 수 있게 했습니다.

다국어 문의 구현 상세
  • 제출 시점의 폼 언어와 응답, 개인정보 동의 버전을 보존하도록 연결했습니다.
  • 문의 목록의 언어 필터와 국제 전화번호 표시를 구현하고, 해외 문의가 Airtable에 동기화되도록 필드를 매핑했습니다.
  • 전화번호 검증, Excel 내보내기, Airtable 매핑을 테스트로 검증할 수 있게 했습니다.

광고 미디어 업로드와 복구

광고 소재 관리 화면과 API, 기존 자산 이관 스크립트를 개발했습니다. 여러 파일을 드래그앤드롭으로 등록하고 대용량 MP4를 S3 멀티파트 업로드로 전송하도록 구현했습니다.

운영자가 자동 생성된 대표 이미지로 영상을 구분하고, 삭제한 파일을 내부 절차로 복구할 수 있게 했습니다.

미디어 관리 구현 상세
  • 브라우저에서 영상의 1초 지점 프레임을 대표 이미지로 생성했습니다.
  • 분할 업로드의 진행률과 재시도·중단 기능을 구현하고, 서버에서 업로드 결과를 검증하도록 했습니다.
  • SQS와 Lambda 워커로 삭제 작업을 비동기 처리하고, S3 백업과 CloudFront 캐시 무효화, 내부 복구를 구현했습니다.

그 외 Growth 기여

  • 광고 세트 등록·수정, 배너·랜딩 디자인 관리, 공통 테이블의 페이징과 정렬을 개발했습니다.
  • 캠페인·소재·랜딩폼의 통계 조회 쿼리를 개선하고 일·주·월 단위 집계 배치를 구현했습니다.
  • 문의 접수 알림톡과 상담 콜 웹훅을 연동하고, 타임아웃과 재전송 중복 처리를 보완했습니다.

사내 업무 자동화와 서비스 운영

n8n 기반 AI 업무 자동화

Notion을 연동한 n8n 워크플로우에서 AI 통합 리서치, 서로 다른 모델 간 교차 피드백, 최종 콘텐츠 생성과 벡터 데이터 적재까지 연결했습니다.

Airtable과 Ghost CMS를 연결해 콘텐츠 초안 생성과 수정·발행 결과 기록도 자동화했습니다.

AI 콘텐츠 생성·발행 자동화 상세
  • AI가 통합 리서치를 수행하고, 서로 다른 AI 모델이 결과에 교차 피드백을 주어 최종 콘텐츠를 만드는 흐름을 구현했습니다.
  • OpenAI Embeddings API로 콘텐츠를 벡터로 변환하고, PostgreSQL의 pgvector에 적재했습니다.
  • 치료 프로그램의 초안이 처음 생성되면 미리보기 링크를 Airtable에 기록해 운영자가 발행 전에 확인할 수 있게 했습니다.
  • Airtable과 Ghost에 기록된 게시물 경로(slug)가 일치하지 않으면 저장을 중단하고, 운영자가 원인을 확인할 수 있도록 오류 메시지를 보완했습니다.

AWS 서비스 인프라 운영·점검

Lambda 기반 API와 배치를 배포하고, 실행 결과와 서비스 운영 상태를 확인했습니다. S3·CloudFront의 파일 제공 경로와 변경한 정적 리소스의 반영 상태도 점검했습니다.

AWS 운영과 배포 스킬 기여 상세
  • CloudWatch에서 API 호출 결과와 예약 배치 실행 상태를 확인했습니다.
  • 프론트엔드 배포 후 정적 리소스 제공 여부를 확인하고, API Gateway와 AWS WAF의 운영 설정과 요청 로그를 점검했습니다.
  • 팀 공통 AI 에이전트의 Lambda 배포 스킬에 기여했습니다. 함수별 배포 대상을 검증해 등록하고 패키징 검증 기록을 보완했습니다.
